## 22.1 Términos pedagógicos

Tabla: Glosario pedagógico

| Término | Definición |
|---|---|
| PIAR | Plan Individual de Ajustes Razonables. Herramienta del Decreto 1421 de 2017 para planear los apoyos y ajustes de un estudiante con discapacidad. En el sistema también aparece como «PR» |
| Ajuste razonable | Modificación o adaptación necesaria y adecuada, que no impone una carga desproporcionada, para que el estudiante participe en igualdad de condiciones |
| Barrera | Obstáculo del entorno (físico, comunicativo, actitudinal, pedagógico) que limita el aprendizaje o la participación |
| DUA | Diseño Universal para el Aprendizaje. Marco con tres principios: múltiples formas de representación, de acción y expresión, y de implicación |
| Caracterización | Descripción del estudiante: contexto, fortalezas, barreras y apoyos requeridos |
| Evidencia | Registro que demuestra la aplicación de un ajuste |
| Seguimiento | Registro de la evolución del estudiante y del cumplimiento de los acuerdos |
| Acudiente | Persona responsable del estudiante ante la institución; su autorización es requisito para crear la cuenta Estudiante |

## 22.2 Términos técnicos

Tabla: Glosario técnico

| Término | Definición |
|---|---|
| API | Interfaz de programación. Conjunto de rutas HTTP que la interfaz usa para leer y guardar datos |
| bcrypt | Algoritmo de hash de contraseñas, lento a propósito para dificultar los ataques de fuerza bruta |
| Checksum | Huella SHA-256 de un archivo de migración, que permite detectar si fue modificado |
| CSP | *Content Security Policy*. Cabecera que limita desde dónde puede cargar scripts la página |
| CSRF | Ataque que hace que el navegador envíe una petición no deseada; se mitiga con el control de `Origin` |
| DML / DDL | Sentencias que manipulan datos (`SELECT`, `INSERT`, `UPDATE`, `DELETE`) / que cambian la estructura (`CREATE`, `ALTER`) |
| Docker | Tecnología de contenedores que empaqueta la aplicación con su entorno |
| e2e | Pruebas extremo a extremo, que recorren flujos completos con la base de datos real |
| HSTS | Cabecera que obliga al navegador a usar siempre HTTPS |
| Migración | Archivo SQL numerado que aplica un cambio de esquema de forma controlada |
| OIDC | OpenID Connect. Protocolo para iniciar sesión con un proveedor externo |
| Railway | Plataforma en la nube que hospeda la aplicación y la base de datos |
| Resend | Servicio de envío de correo por API HTTPS |
| SRI | *Subresource Integrity*. Atributo que verifica que un archivo de una CDN no fue alterado |
| Sesión | Periodo autenticado de una persona, identificado por una cookie con un token aleatorio |
| TLS | Protocolo que cifra la comunicación (HTTPS, conexión a MySQL) |
