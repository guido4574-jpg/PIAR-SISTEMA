# Archivo de evidencia histórica

Los informes de esta carpeta registran auditorías, pruebas y decisiones de fechas anteriores. Pueden mencionar defaults inseguros, migraciones o infraestructura del piloto que posteriormente se modificaron o retiraron. Se conservan como evidencia académica y no son manuales de operación vigentes.

Usa `../VALIDACION_FINAL.md`, `../MANUAL_TECNICO_PIAR.md` y `../MATRIZ_PRUEBAS_PIAR.md` para el estado y procedimientos actuales. La referencia histórica a Railway/Docker no autoriza su uso ni implica conexión activa; la infraestructura piloto fue retirada del código activo. `docker-compose.test.yml` se limita a pruebas locales aisladas.
